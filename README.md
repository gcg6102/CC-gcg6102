# Geanna's Creative Coding Repo                                                             

Please use this tempate to create a repository that contains your coursework for Creative Coding this semester. When you are creating a new item in your repository (either notes from a lecture, or a new assignment) please follow these two steps:

1. make a copy of the "template" folder and rename it to match your given activity (week1 or assignment1, for instance). 
2. add a line to the list in the "index.html" file in the root folder of your repository, which will create a link to your new activity:

```
      <li><a href="./week1/">Week 1 notes</a></li>
      <li><a href="./assignment1/">Assignment 1: Generative Drawing</a></li>
      ...
```
You can simply copy the line above, replacing the directory name with the name of the folder you've just created, and the inner text with a description of the new activity.

I think code is an understanding of how to make problem-solving digestible, not necessarily to the masses, but rather abstracted for their consumption and in theory to make their “lives easier” but often abstracted for everyday needs of the masses. In my previous experience as a computer science major in undergrad, which clearly still shapes me today, our curriculum on technology was focused on understanding each layer of its utilization from assembly language to databases to networks and security, which I still view those things as important, I appreciate the understanding that software can be an object of study, this language makes it more tactical and I’m interested in understanding its components and uses outside of utility, but for encouraging other forms of knowledge and exploration of society and the world. In my opinion, technology is moving more and more from people serving to people surveilling. I think technology works both for and against you and that it depends on your range and understanding of the systems in place made to create these technologies, also whose knowledge is seen as more important in a cisheteropatriarchal society and how one uses that to both navigate, protect, and continue to develop knowledge. Given these circumstances, if code is structured, so is society, so if code can be creative then one can get creative with combating oppression and finding means of liberation in society. I hope to use the freedom of this creative coding and structure to find more methods of seeing the intersection between the areas.
